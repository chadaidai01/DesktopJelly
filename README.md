# DesktopJelly · 桌面图标弹弹弹

让 Windows 桌面图标像软糖一样循环伸缩：底部固定，压扁时变宽，拉高时变窄。

使用 C#、WinForms 和 Windows 原生窗口接口开发，支持调节速度、幅度和目标帧率，可以缩到托盘持续运行。

## 功能

- 变形幅度：5%–65%。
- 动画速度：0.2–10 次/秒。
- 目标帧率：30、60、90、120 FPS。
- 所有图标同步伸缩，或错开节奏。
- 双击动画图标打开对应项目。
- 可选本地 WAV 循环播放，默认关闭。
- 托盘控制、退出快捷键、紧急恢复按钮。
- 导出最近 60 秒的性能诊断 CSV。

## 运行环境

Windows 10 / 11，64 位，.NET Framework 4.x，使用标准资源管理器桌面。第三方桌面替代工具不在支持范围内。

无需安装服务或修改注册表。运行时不需要联网，也不需要 Python、Java 或 ffmpeg。

## 编译和运行

在 Windows 下下载或克隆源码，运行根目录的 `build.cmd`。脚本使用系统目录中的 .NET Framework C# 编译器，不需要安装 NuGet 依赖。

```bat
build.cmd
bin\DesktopJelly.exe
```

如果提示找不到编译器，请检查是否存在：

```text
%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

## 使用

1. 运行 `DesktopJelly.exe`，点击“开始弹弹弹”。
2. 调整变形幅度、速度和目标帧率；勾选“错开节奏”可让图标依次伸缩。
3. 点击“暂停并恢复图标”结束动画，恢复原桌面。

关闭或最小化设置窗口会进入托盘，动画继续运行。双击托盘图标可重新打开设置。

完全退出：托盘菜单选择“退出并恢复”，或按 **Ctrl + Alt + Q**。若图标没有恢复，可使用设置窗口中的“紧急恢复原图标”。快捷键被其他程序占用时，请使用托盘菜单。

运行前请先退出已经打开的旧版本。

### 本地音频

将 WAV 文件命名为 `reference-audio.wav`，放到 `DesktopJelly.exe` 所在目录，然后勾选“自动播放参考音频（本地循环）”。也可以把文件放在源码根目录，编译脚本会将它复制到 `bin`。

推荐使用 44.1 kHz、16-bit PCM WAV。如果需要转换已有音频，可以在安装 ffmpeg 后执行：

```bat
ffmpeg -i input.m4a -vn -ac 2 -ar 44100 -c:a pcm_s16le reference-audio.wav
```

勾选后随动画从头循环播放；取消勾选、暂停或退出会停止，关闭设置窗口后继续播放。音频独立播放，不随动画速度变调，也不会自动匹配节拍。音量可在 Windows 音量混合器中调整。

仓库和发布包不附带音频，请自行准备可使用的音频文件。缺少音频不会影响图标动画。

## 工作原理

程序读取桌面图标的位置和名称，通过 Windows Shell 提取图标图片，在桌面上创建透明动画窗口，再暂时隐藏原图标列表。每一帧改变图标图片的宽高，文字单独绘制，因此不会跟着变形。

邻近的图标会合并到同一动画层中，减少窗口更新次数。后台线程负责安排帧时间，实际绘制在界面线程完成；同一时间最多等待一个绘制回调，避免卡顿时堆积帧。

暂停或退出后，程序销毁动画层并恢复原图标。另有独立的监视进程，在主进程异常退出后尝试恢复图标列表。

## 使用限制

- 动画期间不支持原生的框选、拖动整理和图标右键菜单，需要先暂停。
- 修改桌面布局、图标大小或显示器设置后，请暂停再开始，以重新读取位置。
- 图标来自 Shell 图标接口，图片缩略图、状态角标等外观可能与资源管理器显示不同。
- 目标帧率不等于屏幕实际呈现帧率。性能读数统计程序提交动画的频率，实际流畅度还受显示器、桌面合成和图标数量影响。
- 本项目只处理桌面图标，不包含任务栏动画。

## 性能诊断

点击“保存性能诊断（最近 60 秒）”，在程序目录生成 `DesktopJelly-diagnostics.csv`。程序目录需要有写入权限。

诊断包含帧间隔、绘制及提交耗时、目标帧率、图标数、动画层数，以及设置窗口是否隐藏。排查卡顿时，可以对比设置窗口打开和关闭时的数据。

## 源码结构

| 文件 | 用途 |
| --- | --- |
| `src/DesktopJelly.cs` | 设置窗口、桌面图标读取、帧调度、图标恢复及 Windows 接口 |
| `src/JellyLayer.cs` | 动画层分组、透明绘制及双击命中判断 |
| `src/PerformanceLog.cs` | 性能采样及 CSV 导出 |
| `src/LocalAudioPlayer.cs` | Windows 原生 WAV 循环播放 |
| `src/DesktopJelly.manifest` | 程序权限和 Windows 兼容性声明 |
| `build.cmd` | 编译并输出到 `bin` |
